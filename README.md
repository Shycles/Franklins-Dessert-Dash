# Franklin’s Dessert Dash

Franklin’s Dessert Dash is a side-scrolling game in which the player controls Franklin as he moves across an endless cake-themed environment. 

## Game Instructions

- Press ‘A’ to start playing.
- Press ‘S’ to pause the game.
- Use the up arrow to jump and the down arrow to go down.
- Touching a strawberry with whipped cream earns +1 point.
- Hitting an onion subtracts -1 point.
- Hitting a carrot ends the game immediately.
- Press ‘R’ to play again.
